Android USB tethering for Mac — on Apple Silicon, with your VPN

usb-android-tethering makes your Android phone's USB tethering work on macOS (Sonoma, Sequoia, Tahoe; M1–M4 and Intel). It's a free, open-source HoRNDIS alternative: the phone appears as a real Ethernet adapter, so VPN apps work over it. No kernel extension, no security changes.

Why Android USB tethering doesn't work on a Mac

Most Android phones tether over RNDIS, a Microsoft protocol macOS has never supported. The old fix, the HoRNDIS kernel extension, no longer loads on current macOS, and on Apple Silicon any kext requires lowering the Mac's boot security. Tools that use a tunnel (utun) interface instead are often ignored by VPN apps. usb-android-tethering solves both problems.

Features

🔌 A real Ethernet adapter

macOS's Network framework reports it as wired Ethernet, and it's listed in System Settings → Network as "USB Android Tethering".

🛡️ Works with VPNs

VPN apps run over it like any wired network. Only IPv4 is bridged, so IPv6 can't leak around the VPN.

🤖 Every Android phone

RNDIS (Samsung, Xiaomi, OnePlus, Motorola…) plus CDC-NCM/ECM (Pixel 6+) when macOS doesn't pick the phone up itself.

🍏 Apple Silicon & Intel

One universal binary for M1, M2, M3, M4 and Intel Macs. No kernel extension, no SIP or boot-security changes.

🔁 Plug and play

Starts at boot, connects when you plug in, reconnects after sleep or unplugging, and recovers by itself from crashes.

🪶 Lightweight & open source

Written in Rust, about 7 MB of memory, 0 % CPU when idle. MIT or Apache-2.0 licensed.

How to use Android USB tethering on a Mac

  1. Install by pasting the command above into Terminal. It downloads the universal binary, verifies its checksum, and asks for your password once.
  2. Connect the phone with a USB data cable. Charge-only cables don't carry data.
  3. Turn on USB tethering on the phone. Samsung: Settings → Connections → Mobile Hotspot and Tethering → USB tethering. Pixel: Settings → Network & internet → Hotspot & tethering → USB tethering. Other phones: search Settings for "USB tethering".
  4. You're online. Check with usb-android-tethering status. Unplug and your Mac falls back to Wi-Fi.

Frequently asked questions

How do I use Android USB tethering on a Mac?

Install usb-android-tethering with one command, connect the phone with a USB data cable, and turn on USB tethering in the phone's settings. The Mac connects within a few seconds and shows the phone as the network "USB Android Tethering".

Does HoRNDIS work on Apple Silicon Macs?

No. HoRNDIS is a kernel extension; it no longer loads on current macOS, and on Apple Silicon any third-party kernel extension requires lowering the Mac's boot security. usb-android-tethering is a userspace alternative that needs no kernel extension.

Why doesn't my Mac recognize my Android phone's USB tethering?

Most Android phones tether over RNDIS, a Microsoft protocol that macOS has never supported. usb-android-tethering adds RNDIS support in userspace, and also handles CDC-NCM and CDC-ECM phones that macOS's own driver does not pick up.

Does Android USB tethering work with a VPN on Mac?

Yes. usb-android-tethering presents the phone as a genuine Ethernet adapter, which macOS's Network framework reports as wired Ethernet, so VPN apps run over it like over any wired network. Tunnel-based tools create utun interfaces that VPN apps often ignore.

Is it safe and free?

It is free and open source (MIT or Apache-2.0). It contains no kernel code, opens no network ports, and the installer verifies the release's SHA-256 checksum before installing. Uninstalling removes everything.
